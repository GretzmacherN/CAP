# Analysis workflow
The analysis is performed sequentially through the following notebooks.

## 1: Preprocessing
**Notebook:** `1_Preprocessing.ipynb`

### Inputs
- Raw single-cell RNA-seq data from GSE161529
  https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE161529

### Outputs
- Processed AnnData objects per sample

## 2. Cell-type identification
**Notebook:** `2_Celltype_ID.ipynb`

### Inputs
- Processed AnnData generated by `1_Preprocessing.ipynb`
- `Input_Dataframes/model_from_pal.pkl`

### Outputs
- Cell-type annotations
- CSV files containing annotations/results

## 3. Epithelial reclustering
**Notebook:** `3_Epi_Recluster.ipynb`

### Inputs
- Output AnnData from `1_Preprocessing.ipynb`
- CSV outputs from `2_Celltype_ID.ipynb`
- `Input_Dataframes/MALTA_CURATED_STEMNESS_MARKERS.v2026.1.Hs.gmt`
- `Input_Dataframes/Gavish_cell_state_signature.xlsx`
